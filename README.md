# Audiophile 🎧

**Frontend eCommerce Application for Premium Audio Products**

Audiophile is a modern, responsive frontend eCommerce application built with React. It showcases premium audio products with a clean UI, smooth navigation, and an intuitive shopping experience. This project focuses on frontend architecture, UI/UX, and state management without a backend.

## ✨ Features

* Product listing and detail pages
* Add to cart & remove from cart
* Cart summary with price calculations
* Responsive design for all devices
* Smooth page transitions and animations
* Clean and accessible UI components
* Reusable and modular React components

## 🛠 Tech Stack

* React.js
* JavaScript
* Tailwind CSS / CSS Modules (use what applies)
* React Router
* Context API / useState (for cart state)

## 📂 Project Structure

```
audiophile/
├── src/
│   ├── components/   # Reusable UI components
│   ├── pages/        # Product & checkout pages
│   ├── context/      # Cart state management
│   ├── data/         # Static product data (JSON)
│   ├── assets/       # Images & icons
│   └── App.js
```

## ⚙️ Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/your-username/audiophile.git
```

2. Install dependencies

```bash
npm install
```

3. Run the application

```bash
npm start
```

## 📦 Data Handling

This project uses **static JSON data** to simulate product information. All cart and checkout logic is handled on the frontend using React state management.

## 🎯 Purpose

The Audiophile app was built to demonstrate strong frontend development skills, including component-based architecture, responsive design, state handling, and building real-world eCommerce UI flows without relying on a backend.
